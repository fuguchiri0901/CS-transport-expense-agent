# 運用手順書

## Prompt変更時

1. Copilot Studio の Prompt を変更する
2. `prompts/` 配下の該当ファイルを更新する
3. テストデータで動作確認する
4. 変更内容をコミットする

## Flow変更時

1. Power Automate で Flow を編集する
2. 入出力項目の変更を `flows/` の README に記録する
3. 必要に応じてエクスポート定義を保存する
4. テストデータで動作確認する

## リリース時

1. `releases/` にリリースノートを追加する
2. main ブランチへ反映する
3. Copilot Studio の公開状態を確認する
